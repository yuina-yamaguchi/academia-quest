# アカデミアクエスト

学習をクエスト化する、RPG風の学習管理Webアプリです。
公認会計士試験の学習進捗を「毎日開きたくなる」仕組みでモニタリングできます。

- 完全な静的サイト（バックエンド不要）— GitHub Pages など任意の静的ホスティングにそのまま置けます
- データはブラウザ内（localStorage）に保存
- レスポンシブ対応（PC: サイドナビ / スマホ: ボトムナビ）
- PWA対応（ホーム画面に追加してアプリとして利用可能）

## 機能

- **試験日カウントダウン** — トップ画面に残り日数を大きく表示
- **冒険ランク** — 学習時間からXPが貯まり、ランクが上がっていく
- **学習タイマー** — 1タップで開始/停止。稼いだ時間はそのままXPとポイントに換算
- **デイリークエスト** — 翌 AM4:00 に自動でリセットされる毎日の課題（タイマー開始・目標時間・単元制覇・英単語の復習）
- **ログインボーナス** — 毎日開くと連続日数に応じた報酬（AM4:00基準・7日目で大ボーナス）
- **科目・単元の進捗管理** — 短答式5科目（財務会計論・管理会計論・監査論・企業法・租税法）の標準カリキュラムを収録。単元の追加・改名・削除も可能
- **英単語カード** — 試験対策の英単語を手入力で登録。タップで裏返す暗記カードと間隔復習（10分→1日→3日→7日→14日→30日）。復習は学習記録としてXP・ポイント・デイリークエストに反映
- **学習記録** — セッション履歴、週間グラフ、180日分の学習カレンダー、手入力記録
- **模試・問題集の記録** — 科目別の得点を入力し、達成率をグラフ表示（70%以上で実績解除）
- **星辰ガチャ** — 学習で貯めたポイントで祈りを引く。仲間（属性付き）・称号・枠・背景・装飾・アバターの6カテゴリ・74種類以上を収録。アバターは手描きSVGアート。80連で★5が確定する天井システム付き。コレクション図鑑・重複還元あり
- **実績（アチーブメント）** — 連続日数・累計時間・科目制覇など13種類
- **ギルドカード風プロフィール** — ランク・称号・実績を集約
- **バックアップ** — データのJSON書き出し／読み込み（端末移行・消去対策）
- **複数端末の同期** — GitHubの非公開Gistに自動保存し、PCとタブレット等で自動マージ同期

## ローカル起動

```powershell
cd academia-quest
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。
※ ES Modules を使うため `file://` での直接開きは不可、HTTPサーバー経由で開いてください。

## GitHub Pages へのデプロイ

1. リポジトリを作成し、この `academia-quest` ディレクトリの内容を配置
   （リポジトリ直下に置く場合は `start_url` などはそのままで動作します）
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」に設定
3. ブランチとフォルダ（例: `main` / `academia-quest`）を指定して保存
4. 数分後に発行されたURLへアクセス

サービスワーカーのキャッシュを更新する際は `sw.js` の `CACHE_NAME` を
`academia-quest-v5` のように変更してください。

## 複数端末の同期（GitHub Gist）

同じGitHubアカウントの**非公開Gist**にデータを自動保存し、起動時・変更後に
**自動マージ**で同期します（サーバー不要・静的サイトのまま）。

### 1. トークンを作る（どちらか一方）

- **classic PAT**: [New personal access token (classic)](https://github.com/settings/tokens/new)
  → Scopes は **`gist` のみ**にチェック → Generate
- **fine-grained PAT**: [New fine-grained token](https://github.com/settings/personal-access-tokens/new)
  → Repository access は「No repositories」で可
  → Account permissions → **Gists = Read and write**

### 2. 端末を接続

1. **設定 → ☁️ データ同期** でトークンを入力し「接続して同期を開始」
   （保管庫IDが空欄なら自動検出、無ければ新規作成）
2. 表示された**保管庫ID**をコピー
3. 2台目以降で同じトークン + 保管庫ID を入力して接続

以降は起動時・変更後（約5秒後）・アプリを閉じる時に自動で同期します。
「今すぐ同期」で手動実行もできます。

### マージ規則

- 学習記録・模試・実績・ガチャ所持品・単語カードは **ID単位で和集合**（復習状態は最後に復習した側）
- 科目・単元の**削除・追加・改名も同期**（タイムスタンプが新しい方が勝ち）
- 進捗・設定・デイリーは**更新時刻が新しい方**、連続ログインは最終訪問が新しい方
- ポイントは端末ごとの獲得・消費台帳を**合算**（両端末の成長が消えず、再同期でも二重加算しない）
- XPは学習記録の合計から導出

### セキュリティと注意

- トークンは端末のlocalStorageにのみ保存されます（**JSON書き出しには含まれず**、
  「全データを消去」するとリモートの保管庫ごと削除して同期解除）
- GitHubの Settings → Developer settings からいつでも失効できます
- 同じGitHubアカウントでログインした端末間のみ同期されます
- オフラインの間の変更は、次に繋がった時にマージされます

## データについて

- データはブラウザ内（localStorage）に保存。同期を有効にすれば端末間で自動マージ
- ブラウザのデータ消去で消えてしまうため、**設定 → データのバックアップ**から
  定期的にJSONを書き出すこともおすすめします
- 書き出したJSONは「読み込み」から同じブラウザ／別の端末に復元できます

## ファイル構成

```text
academia-quest/
├── index.html            # アプリのシェル（ヘッダー・ナビ・モーダル）
├── css/app.css           # RPG風テーマ・レスポンシブ
├── js/
│   ├── app.js            # 初期化・ルーティング・イベント・ボーナス演出
│   ├── store.js          # localStorage 読書き・エクスポート/インポート
│   ├── game.js           # XP・ランク・日次リセット・ガチャ・実績のロジック
│   ├── seed.js           # 短答式5科目の標準カリキュラム
│   ├── avatars.js        # 手描きSVGアバター12種
│   ├── sync.js           # GitHub Gist同期・自動マージ
│   └── views/            # 各画面（home / quests / words / record / gacha / profile）
├── manifest.json         # PWAマニフェスト
├── sw.js                 # サービスワーカー（オフラインキャッシュ）
├── icons/                # アプリアイコン
├── generate_icons.py     # アイコン再生成（開発用・Pillowが必要）
├── tests/game.test.mjs   # ゲームロジックの簡易テスト（Node.js）
└── README.md
```

## テスト

```powershell
node tests\game.test.mjs
```

日次リセット・連続日数・XP・ガチャ（80連天井・新タイプ排出）・装備・実績・
エクスポート/インポートに加え、同期マージ（和集合・削除墓標・ポイント台帳・
Gist作成/プッシュのフロー）を検証します。

python generate_icons.py
